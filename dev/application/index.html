Applications: Archimedean Copulas

The ArchimedeanCopulas submodule demonstrates how Nestings.jl enforces mathematical constraints on recursive structures.

1. Abstract Framework

A d-dimensional Archimedean copula is defined as: $C(u_1, \dots, u_d) = \phi(\phi^{-1}(u_1) + \dots + \phi^{-1}(u_d))$ where $\phi$ is the generator of the copula. For nested Archimedean copulas to be valid, the generators must satisfy specific monotonicity requirements. In Nestings.jl, this is handled by a specialized NestingCondition.

Monotonicity and Validation

The condition ensures that for any two nested generators $\phi_1$ and $\phi_2$ (where $\phi_1$ is the parent), the composition $\phi_1^{-1} \circ \phi_2$ is completely monotonic.

Nestings.ArchimedeanCopulas.ArchimedeanMonotonicity — Type
Enforces monotonicity requirement when nesting archimedean copulas.

Core Methods

The framework defines abstract types and common functions for all Archimedean families.

Nestings.ArchimedeanCopulas.Archimedean — Type
Archimedean

Abstract type for the families of archimedean copulas.

Concrete subtypes need an implementation of generator, its inverse and inverse_laplace_trafo.

Optional methods are isless, upper_taildep and lower_taildep.

2. Concrete Implementation: Gumbel

The Gumbel copula is defined by the generator: $\phi(t) = \exp(-t^{1/\theta}), \quad \theta \ge 1$ It is a popular choice for modeling upper tail dependence.

Nestings.ArchimedeanCopulas.Gumbel — Type
Gumbel(theta)

Encodes the Gumbel generator t -> exp(-t^(1 / theta)).

Example

julia> g = Gumbel(1.2)
Gumbel(1.2)

julia> g = Gumbel(1.2); g(2.34)
0.13122268534047923

julia> g = Gumbel(1.2); g.([0,Inf])
2-element Vector{Float64}:
 1.0
 0.0

See also: Archimedean.

source

Construction

Use the nestedcopula function for an intuitive, tuple-based construction.

Nestings.ArchimedeanCopulas.nestedcopula — Function

nestedcopula(c...)

Nest archimedean copulas of the same family. Same syntax as nest(x...) for nesting values.

See also: nest, Copula.

source

Hierarchical Gumbel structure

Condition: $\theta_{root} \le \theta_{child}$ (e.g., $1.5 \le 2.0$)

Construct the nested copula


c = nestedcopula(Gumbel(1.5), (Gumbel(2.0), Gumbel(3.0)), Gumbel(2.5))

Calculate the copula value at a specific point

u = [0.2, 0.5, 0.9, 0.8]
val = mvcdf(c, u)

3. Statistical Analysis

The submodule provides tools for sampling and analyzing the dependence structure.

Nestings.ArchimedeanCopulas.sample — Function
sample(c, n)

Draw n independent samples from copula c.

The order of the columns of the samples corresponds to the order of elements(c). This is the same as the order of elements of the nested tuple t with c = nestedcopula(t...).
